About the Event

The Web Design Competition challenges participants to transform creative ideas into visually appealing and user-friendly websites. This event tests design thinking, layout skills, and basic front-end development knowledge, where participants must design a responsive and attractive web interface within a limited time. It encourages innovation, usability, and aesthetic excellence while simulating real-world web design challenges.
